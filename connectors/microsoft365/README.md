# @unicontext/microsoft365

Microsoft 365 connector (Graph: calendar, Outlook mail, OneDrive metadata, Teams). Delegated OAuth
(Authorization Code + PKCE, loopback) and delta queries; read-only.

Documentation: [docs/connectors/microsoft365.md](../../docs/connectors/microsoft365.md), including how
to register the app in Entra ID and what to do when the tenant requires admin consent.
